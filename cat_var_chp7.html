Marginal effects in interaction model

wage2 <- get(data(wage2))
reg <- lm(wage ~ educ + educ*black, data = wage2)

The function margins::margins() gives SE for both cases of educeffect, i.e. the effect education has on wage for black people and the effect it has for white people. We see that education has a significant positive effect on wage for white people while the effect is insignificant for black people.

  margins(reg, 
          at = list(black = 0:1, 
                    south = 0:1)
          )
  ) %>% 
  filter(factor == "educ") %>% 
  mutate(
    Term = fct(
      case_when(
        black == 1 ~ "Black Workers",
        black == 0 ~ "Non-black Workers"
        )
      ),
    Race = fct(
      case_when(
        black == 1 ~ "Black", 
        black == 0 ~ "Non-black"
        )
      )
  )
